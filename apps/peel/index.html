Peel

A little less file juggling.

A small Mac app for converting files, editing images, and copying text out of screenshots. Drag a file, tap a shortcut, and pick what happens next.

Download for Mac

v0.2.0 · 203 KB ZIP · Free
Apple silicon (M1 or newer) · macOS 13+

What’s inside

A wheel where you’re working
Pick up a file in Finder, tap a shortcut, and drop it on a choice. Switch between formats, editing tools, and file actions without moving the wheel.
Images, sorted
Convert formats, crop, resize, rotate, adjust exposure and saturation, remove metadata, or put images together in a collage or PDF.
Text out of images
Drop a single still image on OCR to read its text locally. Review and edit the result, copy a passage, or copy it all. Handy for screenshots.
A few less PDF chores
Merge and split PDFs, reorder and rotate pages, export embedded text, or turn pages into PNG and JPEG images.
Media and other odds and ends
Audio and video conversion with a separately installed FFmpeg, basic document and text conversions, SRT/WebVTT subtitle conversion, and single-item ZIP creation.
Native and local
Built in Swift using macOS frameworks. The menu bar app opens its editor when needed and handles one conversion at a time. File processing stays on your Mac.

Three shortcuts. One wheel.

Keep holding the file while you tap and release a shortcut. Move to a choice, wait for it to turn blue, then let go of the file. Drop in the center or press Escape to cancel.

Prefer a window? Open Peel from the menu bar and use the editor instead. Conversions save new copies beside your originals.

Getting started

  1. Download and unzip Peel. Drag Peel.app into Applications, then open it.
  2. Peel lives in the menu bar. Grant it Accessibility access in System Settings → Privacy & Security → Accessibility to enable the Finder drag wheel.
  3. Try an image: drag it in Finder, tap Shift, and drop it on a format. Or tap Control and choose OCR to extract text.

This is a personal build and isn’t notarized by Apple. If macOS blocks it and you trust this download, use System Settings → Privacy & Security → Open Anyway after trying to open it.

Audio and video tools need FFmpeg and FFprobe installed separately in /opt/homebrew/bin or /usr/local/bin. They’re not included in this download. Images, PDFs, and OCR use built-in macOS frameworks.

If Tangerine is running, quit it before using Peel’s wheel: both listen for the same drag shortcuts.

The rabbit hole

I stumbled across REA on GitHub, a toolkit for investigating how apps work. I wanted an excuse to try it, and Tangerine’s drag-to-convert interaction was a good one. Could I understand the workflow and build something I’d actually use?

That experiment became Peel: an independent implementation, with native file tools and a wheel that stays close to the drag. Then came image OCR, because copying text out of screenshots is one of those tiny things I do all the time.

It’s still an early personal project, with a smaller feature set than Tangerine. There’s no affiliation, and its proprietary code and bundled helpers aren’t part of Peel.

A few rough edges

This download is for Apple silicon Macs only. OCR handles one still image at a time; scanned-PDF and batch OCR aren’t included. The first recognition can take longer while macOS initializes its model. Large images are limited to 40 megapixels and OCR uses at most 4096 pixels on the longest edge, so tiny text in a large scan can lose detail.

The app is designed to stay small, but conversion and OCR memory peaks haven’t been benchmarked. This build has been checked on my Mac; broader device and macOS compatibility is still a work in progress.
